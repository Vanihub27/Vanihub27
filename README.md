# 👩‍🔬 Sobre mí

Siempre me apasionó comprender cómo funcionan las cosas.

Durante mi formación como bióloga y posteriormente como Doctora en Ciencias Biológicas aprendí a diseñar experimentos, analizar evidencia y formular preguntas relevantes. Con el tiempo descubrí que la Ciencia de Datos ampliaba enormemente esa forma de pensar.

Hoy aplico análisis de datos y Machine Learning para encontrar patrones, construir modelos predictivos y desarrollar soluciones que ayuden a resolver problemas reales.

Disfruto especialmente trabajar en proyectos donde convergen **ciencia, tecnología y datos**.
